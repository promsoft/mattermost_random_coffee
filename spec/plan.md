# Random Coffee Bot — план выполнения

Принцип: каждый этап заканчивается работающим ботом, который можно выкатить.
Спека: [random-coffee-bot.md](random-coffee-bot.md), архитектура: [architecture.md](architecture.md).

- [x] Конфиг (pydantic-settings), подключение к Mattermost (mattermostdriver), эхо-бот в DM

## Этап 1 — MVP: регистрация и пары (спека п. 1, 2, 3, 6, 13)

- [ ] HTTP-эндпоинт для интерактивных кнопок (FastAPI), проверка доставки action'ов
- [ ] Регистрация / пауза / возобновление через кнопки + текстовые команды
- [ ] Профиль: ввод контактов свободным текстом, просмотр/редактирование
- [ ] Матчинг по понедельникам (APScheduler, пока случайный, без рейтинга), кулдаун пар 365 дней
- [ ] Уведомление каждой паре в DM (карточка с профилем партнёра)
- [ ] История встреч в БД, обработка нечётного участника (пул свободных, `unmatched_streak`)
- [ ] Справка (`помощь`): как пользоваться и как всё устроено
- [ ] Анонс в публичный канал после матчинга

**Выкатываем и начинаем пользоваться. Дальше — итерации на живых пользователях.**

## Этап 2 — цикл недели: статусы и оценки (спека п. 4, 5, 8)

- [ ] Среда 14:00 — напоминание + опрос статуса (кнопки: договорились / созвонились / отменили / не связывались)
- [ ] Воскресенье 14:00 — итоговый опрос: состоялась? + оценка 0–5
- [ ] Подсчёт рейтинга (сумма полученных оценок по состоявшимся встречам)
- [ ] Матчинг с учётом рейтинга и приоритета `unmatched_streak`
- [ ] Идемпотентность рассылок + догон пропущенных задач при старте

## Этап 3 — отказ и перенос (спека п. 7, 10)

- [ ] Кнопка «Отказаться от пары»: `declined`, оба в пул, немедленный домэтч из пула
- [ ] Домэтч при регистрации нового участника среди недели
- [ ] Перенос: предложение → согласие (новая встреча на след. неделю) / отказ (встреча несостоявшаяся)

## Этап 4 — админка и жалобы (спека п. 11, 12)

- [ ] Админ-команды: список встреч недели, список участников с рейтингами
- [ ] Отмена любой встречи админом
- [ ] Принудительная пауза / снятие паузы участника
- [ ] Жалоба на партнёра из карточки встречи → пауза обвиняемого + уведомление админам
- [ ] Разбор жалобы админом (снятие паузы)

## Этап 5 — полировка (пост-MVP, по результатам эксплуатации)

- [ ] Icebreaker-вопросы в карточке пары
- [ ] Статистика недели в канал анонсов
- [ ] Напоминание неответившим (мягкий пинг)
- [ ] Бэкап БД (cron-копия файла)

## Definition of Done (для каждого этапа)

- Юнит-тесты на доменную логику (матчинг, state machine встречи — без живого Mattermost)
- Ручная проверка на тестовом сервере / тестовых пользователях
- Обновлён README (команды, переменные окружения)
