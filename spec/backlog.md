# Random Coffee Bot — бэклог идей

Идеи на будущее, не привязанные к этапам [плана](plan.md). Сюда складываем всё,
что может пригодиться; приоритизируем по результатам эксплуатации.

## Оффлайн/онлайн форматы

- Участник указывает предпочитаемый формат встречи: онлайн / оффлайн / любой.
- Оффлайн-пары собираются только из участников одного города.
- В карточке пары бот указывает согласованный формат; для оффлайна может предлагать
  договориться о месте.
- Возможны «городские недели»: бот анонсирует, что в городе X набралось достаточно
  участников для оффлайн-раунда.

## Город участника

- Поле «город» в профиле (выбор из списка или свободный ввод с нормализацией).
- Матчинг учитывает город: для оффлайна — обязательное совпадение, для онлайна —
  опционально как мягкий критерий (например, бонус за разные города для расширения круга
  общения или, наоборот, за совпадение — решить по обратной связи).
- Статистика по городам в канале анонсов.

## Часовой пояс участника

- Поле «часовой пояс» в профиле (или автоопределение из настроек Mattermost-профиля,
  если доступно через API).
- Матчинг избегает пар с большой разницей поясов (порог, например ±4 часа) или
  как минимум предупреждает пару о разнице во времени в карточке встречи.
- Персонализированное время рассылок: напоминания приходят в комфортное время
  по локальному поясу участника, а не по МСК.

## Прочие идеи

- Выбор частоты участия: каждую неделю / раз в две недели / раз в месяц.
- Интересы/теги в профиле и матчинг с учётом общих интересов.
- Личная статистика участника: сколько встреч, средняя оценка, история пар.
- Экспорт статистики для админа (CSV).
